# 问卷或实验数据分析任务

数据文件：`data.csv`（如实际文件名不同，以文件夹内为准）
变量说明：`variable-dictionary.md`

规则：

1. 所有统计结果必须来自数据文件。
2. 所有图表必须由 Python 或 R 代码生成，不要用图片生成模型直接画统计图。
3. 每一步分析都要保留代码。
4. 输出 `reports/data_quality_report.md`、`reports/analysis_plan.md`、`reports/analysis_report.md`、`figures/` 和 `scripts/analysis.py`（或对应的 R 脚本）。
5. 如果变量不适合做某种统计分析，先说明原因，不要硬做。
6. 数据解释和统计方法选择由研究者确认后再作为结论写入报告。
